## The 39 checks (echo_tests, all PASS)

- time accuracy: repeats on their sample; read centroid = delay (whole and fractional)
- generation ratio at 4 rates: gen2 = g(1+R)/2 exactly, then g within 1e-3 (S-1)
- ceiling law: identity to 0.9, then 0.9 + 0.1 tanh, on g·x (the returning term)
- ceiling: past unity the loop parks below 2.0 (input peak + 2 under input) and does not die
- dry path: at mix 0 the output is the input exactly, at 120 % feedback (ADR-142)
- mix 100 %: nothing before the first repeat (no cos(pi/2) leak)
- true bypass: settled-off filters are bit-identical whatever their cutoffs
- loop bound: measured |H_loop| <= 1 at 4 rates x 7 loop settings (D-005)
- sample-rate independence: time exact, loop filter within 0.5 dB at 44.1-192 kHz
- block-size independence: blocks 1, 7, 64, 333, 4096 and random render bit-identically
- determinism: interleaved instances = solo; reset() = fresh
- silence: exact zero in, exact zero out (9 routing x change modes at 120 %; awake engine)
- tail: exact zero from the declared tail on; kInfiniteTail at g >= 1
- tail formula: at 50 / 90 / 99 %, rest never cuts a sounding repeat (D-019)
- tail clock: lowering feedback or releasing a held loop never cuts the repeats (D-019)
- tail near unity: 99.99999999999999 % declares a huge or infinite tail and keeps sounding
- read across the line's wrap: a near-whole delay reads the right sample every lap
- FTZ is set inside process: a subnormal input is flushed
- rest never cuts a sound: the gate waits for the filters' ring below -120 dBFS
- non-finite input: repaired, counted (3 of 3), latched; the output guard too
- loop repair: a non-finite write clears all loop state; the wet recovers
- FTZ: the host's FP control word is restored
- real time: no allocation in process / setParam / reset / loadState
- I/O gain: unity at 0 dB; a 20 ms ramp linear in amplitude, at 48 and 96 kHz (B435)
- switches: routing and filter switches are click-free (20 ms equal-gain)
- crossfade: equal-gain; correlated heads never exceed the signal (D-007)
- jump: a 3 ms crossfade, never a bare jump (D-016)
- fade lengths: jump 3 ms, crossfade time.xfadeMs, at the rate (48 and 96 kHz)
- retrigger: latest target wins, intermediates dropped (SPEC §3.5)
- deferral: a time.change flip mid-fade changes nothing
- tempo: synced 1/4 at 60 bpm repeats at exactly 1 s from the first block, no glide in
- clamp: synced times fold by halving, free times clamp, 1 ms floor (SPEC §3.4)
- routing: ping-pong alternates; stereo never crosses; right wakes; M/S levels; M/S folds to M
- load: old repeats fade (not cut) and end within 20 ms; Device keys untouched (D-016)
- load: the old audio fades under its old settings, click-free (D-020)
- load: a second load mid-fade never restarts the fade (D-020)
- load: Device gain ramps run on through a load (RS-4.5)
- sleep: a slept instance equals its never-slept twin from the wake on
- parameters: unknown / non-finite / out-of-range / fractional values refused
