# Echo — cost (1.0 bar rows 13 – 15)

GENERATED by `echo_bench --md > docs/cost.md` (core/tools/bench.cpp, T-020, D-045) on Apple M3. **CPU is Layer-E: measured and
reported, never a gate (RS-8.3).** horde measures every module itself on its own bench (RS-8.2); these figures are indicative.

**Protocol:** horde's B441-3 (`docs/port/cpu-ledger.md` §1, last changed at `271f275`), adapted to an FX module (D-045): Release
`-O3 -ffp-contract=off`; 128-sample blocks; 0.25 s untimed, 2.0 s timed (one clock pair, control moves inside); best of 5
interleaved; calibration 1e8 dependent multiply-adds; the load guard (1-minute load ≤ 3.0 and no other process ≥ 50 % of a core;
`--md` refuses `--force`). **Min-spec = M3 × 1.5: AN ASSUMPTION** until measured once on an M1 base or the Intel min-spec.
Budgets (RS-8.1; Q-A3 closed by D-028): ≤ 2 % of a min-spec core at the defaults, ≤ 4 % at the worst; the automated and morph
rows are read against the 4 % (the lead's reading, D-045). Stimuli: seeded noise at −12 dBFS (L and R decorrelated) and horde's
B265 chord at −6 dBFS. **Evidence** columns show each row's move happened in the timed window: the blocks whose moved key changed,
the time fades and D-006 fallbacks on line 0, and its read-speed range.

## Memory per instance (row 15; SPEC §11)

Every byte `prepare()` allocates, with a 4096-sample maximum block (the block size allocates nothing); nothing is allocated after it. A **high-water mark**: the lines are never shrunk, so an instance re-prepared at a lower rate keeps the larger figure. Plus `sizeof(Echo)` (2.5 KiB).

| rate | MiB | of which the two lines |
|---|---|---|
| 44.1 kHz | 4.30 | 4.04 |
| 48.0 kHz | 4.68 | 4.40 |
| 96.0 kHz | 9.35 | 8.80 |
| 192.0 kHz | 18.71 | 17.61 |

**Beyond one instance (RS-8.4).** Echo starts no second instance during a flip or a load: a load and a Clear fade the old repeats
inside the one engine. Spill-over tails are horde's. **When M4's impulse-response display is open, its render service
(`ir_service.h`) holds one more prepared `Echo`** for the offline clone: the same memory again, off the audio thread.
